GALAXY MEMORIES — IMAGEKIT EDITION
===================================

Đã cấu hình sẵn:
- URL endpoint: https://ik.imagekit.io/akf
- Root folder: /YTC_Memories
- Các thư mục năm: 1, 2, 3, 4, 5, 6, 7, 8

MỤC TIÊU
- Không cần đổi tên ảnh.
- Không cần copy link từng ảnh.
- Chỉ upload ảnh vào đúng thư mục năm rồi chạy 1 file cập nhật.

LẦN ĐẦU
1. Cài Node.js 18+ nếu máy chưa có.
2. Chạy SETUP-IMAGEKIT.bat.
3. ImageKit Dashboard -> Developer options -> API keys.
4. Tạo/ưu tiên Restricted API Key chỉ có Media management = Read.
5. Dán PRIVATE KEY vào imagekit.private.json rồi Save.
6. Chạy UPDATE-IMAGES.bat.
7. Mở index.html.

MỖI LẦN THÊM/XÓA ẢNH
1. Upload/xóa ảnh trên ImageKit trong YTC_Memories/1 ... /8.
2. Chạy UPDATE-IMAGES.bat.
3. images.js + images.json sẽ tự cập nhật toàn bộ danh sách.
4. Upload lại các file public lên host.

FILE NÀO UPLOAD LÊN HOST?
- index.html
- images.js
- (images.json không bắt buộc cho web chạy, nhưng nên giữ)

KHÔNG UPLOAD:
- imagekit.private.json

TỐC ĐỘ
- Card ngoài thiên hà dùng thumbnail ImageKit 640px, quality 72.
- Click ảnh mới mở file gốc.
- Vì vậy không còn tải ảnh gốc hàng loạt như Google Drive.

GHI CHÚ
- images.js mẫu đi kèm đã chứa ảnh mẫu:
  /YTC_Memories/1/7c4d8b63512d49c2a46b20684f3961c8.jpg
- Sau khi chạy UPDATE-IMAGES.bat, file này sẽ được thay bằng danh sách thật của toàn bộ thư mục.
