Cách thêm ảnh mới
  1. Upload ảnh vào YTC_Memories/1 … YTC_Memories/8. Giữ nguyên tên file, không cần đổi tên.
  2. Chạy UPDATE-IMAGES.bat trên Windows.
  3. Script tự lấy mọi tên file từ ImageKit và cập nhật images.js + images.json.
  4. Upload lại project lên host. Không đưa file imagekit.private.json lên host.

Không tải được Three.js
